# ODyan
Continuous Opinion Dynamics Architecture (CODA) is a systematic and extensible computational framework for understanding the emergence of collective opinion patterns in complex social networks.

The Computational Opinion Dynamics Architecture (CODA) is a Python-based computational framework designed to investigate how individual opinions evolve, interact, and aggregate within social networks. The project provides an integrated environment for implementing, simulating, and comparing opinion dynamics models under different network structures and parameter configurations.

The framework incorporates three opinion dynamics approaches: the Deffuant–Weisbuch (DW) model, the Hegselmann–Krause (HK) model, and a proposed Centrality-Weighted Influence Model (CWIM). While DW and HK represent established approaches to modelling social influence and opinion convergence, CWIM introduces a heterogeneous influence mechanism in which an individual's influence depends on both network centrality and opinion similarity. This mechanism allows the framework to examine how structural prominence and social affinity jointly shape opinion evolution.

CODA supports computational experiments across multiple network topologies.
